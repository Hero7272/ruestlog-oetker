# RüstLog · Pulverabfüllung

Offline-Webapp für Rüstbegleitung. **Im Repo liegt nur die App-Hülle.** Einträge, Fotos und Zeiten bleiben im Browser auf dem Gerät.

## Seite

https://hero7272.github.io/ruestlog-oetker/

## Pages einschalten

1. Repo → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, Ordner: **/ (root)**
4. Speichern. Nach 1–2 Minuten ist die URL live.
